# POP! Shop — React & Three.js 3D Store

Сучасний інтерактивний веб-магазин колекційних вінілових фігурок **Funko POP!**, повністю переписаний на **React 19**, **Three.js** та **Tailwind CSS**.

---

## 🚀 Нові можливості та 3D фічі

1. **Інтерактивний 3D Showroom (Three.js)**:
   - Деталізована 3D коробка Funko POP з вініловим прозорим вікном, номером та серією.
   - Вінілова 3D фігурка з пропорціями Funko (характерна кубічно-скруглена голова, глянцеві очі, аксесуари героїв).
   - Вільне обертання мишкою або тачем на 360°.
   - Функція **"Відкрити 3D / Розпакувати" (Unbox 3D)**: кришка коробки відкидається, а фігурка злітає вгору та парить у повітрі.
   - Перемикач освітлення (Studio / Cyber Neon / Gold).
   - Швидкий вибір фігурок прямо у 3D сцені.

2. **3D Quick View Modal (Детальний 3D Огляд будь-якого товару)**:
   - Кнопка **"3D Огляд"** на кожній картці товару відкриває повноцінне модальне 3D вікно з зумом, обертанням і розпаковкою.

3. **3D Background Particles**:
   - Інтерактивні плаваючі вінілові куби та зоряний пил на Three.js з ефектом паралаксу від курсору миші.

4. **Автентичний кастомний перемикач теми**:
   - Анімований SVG-перемикач (Сонце / Місяць / Хмари / Зірки / Кратери) з збереженням у `localStorage`.
   - Автоматична зміна логотипів та 3D освітлення під світлу та темну тему.

5. **Горизонтальні каруселі з інерцією (Momentum Drag-Scroll)**:
   - Плавне перетягування мишкою з фізикою ковзання, як у мобільних додатках.

6. **Повнофункціональний магазин**:
   - Каталог з живим пошуком та фільтрами категорій (Marvel, Disney, Ексклюзиви).
   - Сортування за ціною та популярністю.
   - Кошик покупок з промокодами (наприклад, `POP2026` на 15% знижки), розрахунком доставки та анімацією конфетті при замовленні.
   - Модальне вікно авторизації та реєстрації з збереженням сесії.

## 🛠 Запуск проекту

```bash
# Встановлення залежностей (якщо потрібно)
npm install

# Запуск сервера розробки
npm run dev

# Збірка для продакшну
npm run build

# Попередній перегляд збірки
npm run preview
```

## Telegram-бот для заказов

Бот: [@popshop_orders_ua_bot](https://t.me/popshop_orders_ua_bot), имя **POP! Shop Заказы**, логотип POP! Shop установлен. Он принимает заказы из Telegram и локального сайта, хранит их в общем журнале `bot/orders.jsonl` и отправляет менеджеру уведомление с кнопкой открытия заказа. На сайте покупатель указывает имя, email, телефон и адрес доставки. Менеджерская панель открывается командами `/manager` или `/admin`: там можно смотреть заказы, открывать детали и менять статус. Заказы из веб-формы помечаются как ожидающие оплаты: текущий checkout сайта имитирует платёж и не подтверждает реальную транзакцию. Покупатель Telegram-бота может выбрать оплату при получении или онлайн-счёт Telegram. Для онлайн-платежей нужен токен платёжного провайдера из BotFather в `TELEGRAM_PAYMENT_PROVIDER_TOKEN`; успешный платеж сверяется с валютой и суммой заказа перед подтверждением.

1. Токен бота и `TELEGRAM_ADMIN_CHAT_ID` сохранены в локальном `.env`. Для онлайн-платежей добавьте туда токен провайдера из BotFather; пока он не задан, покупателю доступна оплата при получении, а кнопка онлайн-оплаты не создаёт фиктивный заказ.
2. Для отправки заказов с сайта оставьте запущенным `npm run dev` (локальный endpoint `/api/orders` использует серверный токен и доступен только в dev-сервере). Запустите `npm run bot`, чтобы обрабатывать панель менеджера и Telegram-заказы.
3. После изменений товаров или цен обновите каталог бота командой `node bot/sync-catalog.mjs`.
